# DATASCI 506 Homework 3

This repository contains the complete R/Quarto solution for Homework 3:

- NHANES audiometry data cleaning and Poisson regression
- Sakila database analysis using both R and SQL
- Australian sample-record string processing and Benford's law analysis

## Files

- `hw3.qmd`: reproducible Quarto source
- `hw3.html`: self-contained rendered submission
- `DATASCI-506-hw3.Rproj`: RStudio project
- `data/`: source datasets used by the analysis

Open `DATASCI-506-hw3.Rproj` in RStudio, then render `hw3.qmd` to reproduce the HTML output.
